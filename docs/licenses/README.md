# License text provenance

These files supplement, and do not replace, the original `COPYING.md` and source
headers. The Windows package places this directory at `licenses/release/`.

- `GPL-3.0.txt`: verbatim application `LICENSE`.
- `Prism-branding-CC-BY-SA-4.0.txt`: verbatim `program_info/LICENSE`.
- `libnbtplusplus-*`, `qdcss-*`: original bundled library licenses.
- `rainbow-LGPL-2.0.txt`: full GNU Library GPL version 2 from
  https://www.gnu.org/licenses/old-licenses/lgpl-2.0.txt. The upstream rainbow source
  headers allow version 2 or later; the upstream `COPYING.LIB` was empty.
- `LocalPeer-BSD.txt` and `MurmurHash2-public-domain.txt`: original source headers.
- `resources/`: original resource license sidecars.
- `vcpkg/`: verbatim installed package copyright/license files for the release's
  runtime dependencies. Source/provenance accompanies the dependency-source asset.
- `NSIS-3.12.txt`: verbatim `COPYING` from the official NSIS 3.12 distribution.
- `Microsoft-Visual-Cpp-Runtime-14.44.rtf`: original embedded license from Microsoft's
  signed `vc_redist.x64.exe` version 14.44.35211; the included runtime DLLs retain
  Microsoft's terms.
- `qt-6.5.3/`: original module license texts, attribution metadata and every
  referenced license file from the official Qt 6.5.3 source archive. See its index.
- `Material-Design-OFL-1.1.txt`: the copyright notice retained in `COPYING.md`,
  followed by the official SIL Open Font License 1.1 text.
