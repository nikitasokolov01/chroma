# Chroma 1.0.0

**First stable release · Windows x64 · 2026-10-08.**
Get the installer, portable package, checksums, and matching source archives on
the [v1.0.0 release page](https://github.com/nikitasokolov01/chroma/releases/tag/v1.0.0).

## Skin Studio

- **Outfit presets:** save a named skin, Classic or Slim model, composed Skin
  Extras, and an optional owned cape selection. Preview, rename, and delete
  presets locally across sessions. Applying an outfit checks the selected
  account's cape ownership before upload and explains incompatible presets.
- **Mirror painting:** mirror across a body part or between matching limbs,
  with separate controls and a shared undo history in the 3D and texture views.
- **Palette swapping:** compare large, synchronized **Current skin** and
  **Preview** models in the workspace. Scope colors to body parts and layers,
  choose replacements with the floating picker, then apply or cancel the swap.
- **Texture brush:** add fine grain, fabric, or hair shading from existing skin
  colors, with contextual texture controls and a live preview.
- **More editing tools:** bucket fill, marquee selections, Shift painting beneath
  the outer layer, hue and brightness adjustments, reference skins, copy/paste,
  and a local Skin Extras inventory for reusable pieces.

Editing, outfit saving, and PNG export work without an account. Applying skins
or capes requires an eligible Microsoft account with a Minecraft Java profile.
Devices without OpenGL retain image previews and the 2D editor. See the
[Skin Studio guide](../SKIN-STUDIO-TOOLS.md) for controls and limits.

## Launcher interface

- **Update notices:** a notice shows the available version and a short feature
  summary. **What’s new** opens the release review without discarding the current
  page or unsaved work; **Later** hides that notice for the session. Download and
  installation still require the user's actions and checksum verification.
- **Windows controls:** flat, themed minimize, maximize/restore, and close
  buttons sit in a dedicated strip at the top-right, above the navigation bar.
  The native Windows caption is disabled so its buttons cannot peek through
  the windowed frame. Window dragging, resizing, and snapping remain available.
  Native mouse clicks now reach the custom maximize/restore button, and mouse
  use does not leave a keyboard-focus outline on the minimize button.
- **Windows icon:** the application supplies the Chroma logo to every top-level
  window, and the installed shortcut explicitly selects the executable's logo.
- The release includes the current native library, instance and modpack views,
  inline settings, account tools, light and dark clay themes, custom accents,
  and support for opening an existing Prism profile.

## Windows release set

The release metadata is **1.0.0**, with Windows executable version **1.0.0.0**.
The release is built from the **v1.0.0** Git tag on `main`, retaining that exact
revision in the application and corresponding source archive.

Release assets (also generated locally under `dist/release/v1.0.0/`):

- `Chroma-1.0.0-Windows-x64-Setup.exe`
- `Chroma-1.0.0-Windows-x64.zip`
- `Chroma-1.0.0-source.tar.gz`
- `Chroma-1.0.0-dependency-sources.tar.gz`
- `qt-everywhere-src-6.5.3.tar.xz`
- `package-manifest.json`
- `SHA256SUMS.txt`

The installer uses a per-user installation. The portable ZIP keeps its default
profile beside the executable. Existing account data, instances, worlds, Skin
Extras, and outfit presets must survive updates. The
[release guide](../CHROMA.md#release-versions-and-windows-installer) documents local
build, source archive, checksum, and package tests. Versions 0.3.0 and later can
find this stable release through Chroma's update check; older versions require
a manual download. Close Chroma before running the installer manually.

## Validation and limitations

Validation covers the core test suites, the native application UI, and nine
update-helper preservation/rollback scenarios. All 17 native Windows frame checks
pass at both 100% and 150% scaling, including queued mouse press/release,
repeated maximize/restore, fullscreen return, and canceled presses. The fallback
frame run passes 12 checks with five native-only skips. Native and fallback UI
checks cover controls, inherited icons, themes, unsaved-edit protection, compact
reference editing, and update notices. Full-frame screenshots verify that native
Windows buttons no longer appear at the edge.

The final executable builds as version 1.0.0.0. Installer checks pass for initial
installation, upgrade from 0.3.0.0, clean-PATH startup, uninstall, and profile
preservation. Both installed and portable updates from 0.3.0.0 to 1.0.0.0 pass,
preserving synthetic accounts, settings, worlds, Skin Extras, and outfit presets.
The upgraded executables match the release build by SHA-256.

Tests use isolated synthetic profiles and do not prove a live Microsoft
sign-in, Minecraft launch, or real account skin/cape upload. Release packages
currently target Windows x64. The public Microsoft OAuth application identifier
continues to use Prism's registration; the consent screen may name Prism Launcher.
