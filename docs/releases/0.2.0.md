# Chroma 0.2.0 preview

**2026-09-28 · Windows x64**

This release adds Skin Studio and expands the native launcher interface introduced
in v0.1.0. Chroma remains an independent fork of Prism Launcher 10.0.5.

## What's new since v0.1.0

- **Paint skins directly in 3D.** Skin Studio opens on a Classic or Slim model.
  Switch to the 2D texture with a live preview while keeping the same edits,
  selected color, and undo history. Brush, eraser, picker, and pan/rotate tools use
  compact icons and B/E/I/H shortcuts.
- **Keep color and layer controls close.** The color wheel, hex field, and opacity
  slider stay visible while other controls scroll. Show or hide each body part's
  base and outer layers independently. Import/export PNGs, undo strokes, save to
  the local library, or apply a saved skin to an eligible Microsoft account.
- **Open skins and accounts from the sidebar.** The skin account dropdown updates
  skins, capes, and the upload target without changing the default launch account.
  Local skin editing also works with no account added. Account profiles show the
  face, name, UUID, model, and status.
- **Arrange larger instance libraries.** Drag cards into a saved manual order or
  onto the sidebar to pin them. Name and last-played sorting remain available.
  Visible-card painting and cached geometry reduce work in large libraries;
  progress updates avoid full layouts and the idle background stops repainting.
- **Browse projects inside the launcher.** Modrinth and CurseForge share About,
  Gallery, and Releases views, with cached metadata available offline. Provider,
  settings, account, and instance flows open in the inline workspace.
- **Smoother native controls.** Menus, scrolling, focus restoration, and hand
  cursors are more consistent. Light/dark themes and accents extend to the Windows
  caption while keeping native window controls. Reduced-motion preferences are
  respected.

The first skin preview now preserves the launcher window instead of causing Qt to
recreate it. Preview composition also keeps neighboring controls intact during
resizing and scrolling. Devices without a working 3D preview retain 2D editing.

The [v0.2.0 release page](https://github.com/nikitasokolov01/chroma/releases/tag/v0.2.0)
provides these packages:

| Package | Download |
| --- | --- |
| Per-user installer | [Chroma-0.2.0-Windows-x64-Setup.exe](https://github.com/nikitasokolov01/chroma/releases/download/v0.2.0/Chroma-0.2.0-Windows-x64-Setup.exe) |
| Portable ZIP | [Chroma-0.2.0-Windows-x64.zip](https://github.com/nikitasokolov01/chroma/releases/download/v0.2.0/Chroma-0.2.0-Windows-x64.zip) |

Close Chroma before updating. With the installer, select the existing Chroma
installation; its default profile is stored separately in `%APPDATA%\Chroma`.
For portable use, extract the ZIP to a new folder and run `chroma.exe`.

To reuse an existing portable or Prism profile, choose **Launcher menu (•••) →
Use Prism folder…** and select the folder containing `prismlauncher.cfg`. Keep that
profile folder: it contains the instances and other launcher data. Chroma restarts
once and remembers the selection. Keep Prism closed while sharing its profile.
See the [profile guide](../CHROMA-MIGRATION.md).

Updates are downloaded from Releases; the upstream binary updater is disabled.
Java and Minecraft are not bundled. Microsoft sign-in may identify Prism Launcher
because this preview retains its public application ID.

Matching source assets accompany the binaries: `Chroma-0.2.0-source.tar.gz`,
`Chroma-0.2.0-dependency-sources.tar.gz`, and `qt-everywhere-src-6.5.3.tar.xz`.

## Verification

The implementation passed the Windows Qt 6.5.3/MSVC build, **31/31 CTest suites**,
**42/42 native Windows UI cases**, and **42/42 offscreen UI cases**, including the
fallback editor. Checks cover 3D picking and painting, undo, visibility, color
controls, first-open window stability, compact layouts, and a 4,000-instance library.

Installer and package verification results are recorded on the GitHub release
page. The automated checks do not establish a real
Microsoft sign-in, skin upload, Minecraft session, or live provider installation.
macOS and Linux builds were not exercised. Details are in the
[verification record](../UI-MODERNIZATION.md#skin-studio-3d-painting-verification--2026-09-28).

## Preview versioning

While Chroma remains a `0.x` preview, feature releases increase the minor version
(for example, `0.1.0` to `0.2.0`). Fixes within a feature release increase the patch
version (for example, `0.2.0` to `0.2.1`).
