# Chroma 0.3.0 preview

**2026-09-29 · Windows x64**

This release adds clearer Skin Studio controls and Chroma's own release updater.
Chroma remains an independent fork of Prism Launcher 10.0.5.

## What's new since v0.2.0

- **Pixel grids on both 3D layers.** The grid follows the body and outer surfaces,
  including transparent outer pixels. Both grids appear when both layers are
  visible. The Grid control works in the 3D and 2D editing views.
- **A clickable body diagram.** Toggle the head, torso, arms, and legs directly.
  Each part button controls both layers and supports Tab and Space. Separate
  **Body** and **Outer layer** buttons show or hide each layer globally.
- **Painting follows the outer layer.** While Outer layer is visible, painting
  changes only that layer. Hide it to paint the body. Hidden parts cannot be
  painted, and hiding both layers stops painting. These rules also apply in 2D.
  The color wheel, hex field, and opacity remain visible in compact windows.
- **One launcher menu in the header.** Click **Chroma** at the top of the window
  for profile selection, accounts, instance commands, and update checks. The
  sidebar overflow button is removed.
- **GitHub release updates.** Chroma checks for newer releases automatically,
  including prereleases by default. Checks can be disabled in
  **Settings → Launcher → Updater**. Manual checks remain available from the
  Chroma header menu. Downloads and installation each require your action.

**Upgrading from 0.2.0 or earlier requires a manual download once.** Close Chroma
and install 0.3.0. The installer keeps its default profile in `%APPDATA%\Chroma`.
For portable use, extract to a new folder and retain your existing profile folder.
Choose **Chroma header menu → Use Prism folder…** to reuse the folder containing
`prismlauncher.cfg`; see the [profile guide](../CHROMA-MIGRATION.md).

From 0.3.0, automatic checks offer future Chroma releases. You can also select
**Chroma header menu → Check for updates…**. Choose **Download update** to fetch an
available update. Chroma verifies the file against the release's SHA-256 checksum
before offering **Install and restart**. Checking for an update does not download
or install it. In **Settings → Launcher → Updater**, turn off **Check for updates
automatically** to use manual checks, or clear **Include prereleases** to limit
offers to stable releases. **Check for updates now** runs a manual check there.

Java and Minecraft are not bundled. Microsoft sign-in may identify Prism Launcher
because this preview retains its public application ID.

Matching source assets accompany the binaries: `Chroma-0.3.0-source.tar.gz`,
`Chroma-0.3.0-dependency-sources.tar.gz`, and `qt-everywhere-src-6.5.3.tar.xz`.
The release also includes `SHA256SUMS.txt` and `package-manifest.json`.

## Preview versioning

While Chroma remains a `0.x` preview, feature releases increase the minor version
(for example, `0.2.0` to `0.3.0`). Fixes within a feature release increase the patch
version (for example, `0.3.0` to `0.3.1`).
